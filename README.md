# 多级分销商城微信小程序

这是一个从零搭建的微信小程序示例，包含多级分销商城的核心页面结构与示例数据，方便继续扩展商品、订单与佣金逻辑。

## 功能概览
- 首页活动与运营概览
- 商品列表与详情页（含分销推广码）
- 购物车与结算入口
- 分销中心（等级、团队、佣金规则）

## 本地预览
1. 使用微信开发者工具导入当前仓库目录。
2. 在 `project.config.json` 中替换为你的真实 `appid`。
3. 点击工具栏「编译」即可预览。

## 部署到微信公众平台（小程序后台发布）
1. 注册并认证微信小程序账号，获取 `AppID`（小程序后台 -> 开发 -> 开发管理 -> 开发设置）。
2. 在微信开发者工具中导入当前项目，并将 `project.config.json` 的 `appid` 替换为你的真实 `AppID`。
3. 在开发者工具中完成基础功能测试后，点击「上传」并填写版本号与项目备注。
4. 登录微信公众平台 -> 版本管理，提交审核并等待审核结果。
5. 审核通过后，点击「发布」即可完成上线。

> 提示：如果涉及支付/分销等能力，需在小程序后台配置对应的类目、接口权限、服务器域名等，具体以微信公众平台的最新要求为准。
